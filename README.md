# 小索 · 深求者 / DeepSeeker

DeepSeek 娘「小索」的横版动作小游戏。AI 大战背景，Boss 用真实模型名 + 外号。
横屏手机点开即玩，键盘 / 触屏双支持。

**当前版本：第一章 Demo（第 1 关 · 机房深井）**

---

## 玩法

| 系统 | 说明 |
|---|---|
| 生命 | 血条叫「上下文窗口」，归零即「掉线重连」 |
| 思考条 | 命中与受击积攒，满 100% 进入**思考模式**：世界减速到 0.42 倍、伤害 ×3、左侧滚动推理链 |
| 推理爆发 | 思考模式中再按一次，或能量耗尽，触发范围爆发并清空敌方弹幕 |
| 永久碎片 | 击败 Boss 获得（本 Demo 为「糖分护盾」） |

## 操作

**桌面**：`A / D` 移动，`空格` 跳，`J` 冲撞，`U` 射击，`E` 思考

**手机**：左摇杆移动，右下四键「跳 / 弹 / 冲撞 / 思考」

## 第 1 关 · 机房深井

三层检修栈道，脚下是无底机柜井（掉下去扣血并回到检查点）。

- **数据甲虫**：地面巡逻，接触掉血
- **幻觉幽灵**：飘浮追击，半透明周期内无敌
- **Boss 豆包「奶茶店员」**：抛物线珍珠（落地生成减速糖水）、近身横扫、召唤甲虫；血量低于 50% 后攻击提速

## 技术

- 单页 H5，Canvas 2D，原生 ES Module，无框架无构建
- 逻辑分辨率 480×270，等比缩放适配任意屏幕
- 角色与特效**程序化绘制**（可做任何帧动画），背景使用 AI 概念图视差
- WebAudio 实时合成音效，localStorage 存最高分

## 本地运行

```bash
python3 -m http.server 8123
# 打开 http://127.0.0.1:8123/index.html
```

```
src/render.js       # 程序化绘制

art/web/            # 线上用压缩图（jpg）
```
